# PEAK — вёрстка и анимации сайта

Oct 14, 2026 · @Vehcadrob

## Обзор

Сайт PEAK — одностраничник на 12 сценах, собранный по скролл-механике verostudio.com и наполненный только контентом из `DJ_PEAK_InterPK.html`: биография, 6 KPI, 6 глав таймлайна, 12 резиденций, 5 платформ, портрет и логотип.

С verostudio взяты только приёмы и параметры движения, замеренные в живом DOM на вьюпорте 1440×900: композиция секций, тип каждого эффекта, дистанции скролла, кривые. Код, тексты, фото и шрифты оригинала не использовались — у Vero проприетарные гарнитуры Louize Display и Beausite Classic, 3D-модель на WebGL и свои съёмки.

**Что замерено на оригинале**

- Стек: Next.js (Turbopack), CSS Modules на SCSS, без GSAP, Lenis, Locomotive, Three.js в глобальном скоупе. Анимации — CSS transitions/keyframes плюс собственный JS, пишущий `transform` и `clip-path` по скроллу.
- Высота документа ≈ 15 950 px при 900 px вьюпорта (≈ 17,7 экрана).
- 21 кривая в токенах — стандартные кривые Пеннера (`ease-out-quart`, `ease-in-out-quart`, `ease-out-expo` и т.д.). Самые частые длительности: 0,3 с (16 правил), 0,2 с (9), 0,28 с (6), 1 с (5).
- Сетка: 12 колонок, gap 10 px, поля 30 px.

**Файлы сборки**

| Файл | Что внутри |
| --- | --- |
| `index.html` | вся вёрстка, CSS (14 блоков) и JS-движок в одном файле |
| `assets/logo.png` | логотип PEAK, обрезан по альфе, 1400×323 |
| `assets/portrait.jpg` | официальный портрет, 1600×2400 |
| `assets/*-duo.jpg`, `*-mono.jpg` | кропы портрета (лицо, руки, очки, молния) в дуотоне и ч/б |
| Lenis 1.1.13 | единственная библиотека, с jsDelivr |

**Главное правило движения.** Эффекты делятся на два типа, и путать их нельзя:

| Тип | Что значит | Где используется |
| --- | --- | --- |
| Triggered | скролл пересекает линию → анимация играет сама, со своей длительностью и кривой | весь текст, появление фото, плиток, кнопок |
| Scrubbed | позиция скролла = плейхед, без длительности | маска hero, логотип, рост и шторки степпера, параллакс, разъезд цитаты, логотип в футере |

Текст никогда не привязан к скроллбару: заскрабленная прозрачность текста — главный признак дешёвого клона.

## Движок скролла

Вся скраб-анимация идёт через один `requestAnimationFrame` и одну функцию `tick()`; триггерные появления — через один `IntersectionObserver`. Никаких GSAP и ScrollTrigger: как и на оригинале, движок — это несколько десятков строк своего JS.

**Слои**

1. **Ввод → Lenis.** Колесо сглаживается (`lerp: 0.1`), тач остаётся нативным (`syncTouch: false`). Lenis скроллит настоящий `window`, поэтому `position: sticky` и `fixed` работают без прокси.
2. **rAF-цикл.** Один на всю страницу: сначала `lenis.raf(time)`, потом `tick(time)`.
3. **`tick()`.** Читает `y` один раз, считает прогресс каждой сцены от 0 до 1 по закэшированным офсетам и пишет только `transform`, `clip-path`, `opacity` и CSS-переменные.
4. **`measure()`.** Кэширует `top`/`height` секций, выставляет высоту степпера. Запускается на старте, на `resize`, после `document.fonts.ready` и `load` — поздний шрифт меняет высоты заголовков.
5. **IntersectionObserver.** `rootMargin: 0 0 -12% 0`: элемент получает `.is-in`, когда его верх пересекает 88 % высоты экрана, один раз. Дальше всё делает CSS transition.

```js
const lenis = new Lenis({ lerp: 0.1, smoothWheel: true, syncTouch: false });
const map = (v, a, b) => Math.min(1, Math.max(0, (v - a) / (b - a)));   // прогресс 0…1

function raf(time) { lenis.raf(time); tick(time); requestAnimationFrame(raf); }
requestAnimationFrame(raf);

function tick(time) {
  const y = lenis.scroll;
  // каждая сцена: p = map(y, start, end) → запись transform / clip-path
}

const io = new IntersectionObserver(es => es.forEach(e => {
  if (e.isIntersecting) { e.target.classList.add('is-in'); io.unobserve(e.target); }
}), { rootMargin: '0px 0px -12% 0px' });
```

**Два механизма триггера.** Обычные секции получают `.is-in` от IO навсегда. Внутри sticky-сцен элемент физически не двигается, поэтому IO не годится: фаза включается из `tick()` по окну прогресса функцией `setPhase()`. При выходе из окна ставится `.is-out` — строки уезжают вверх, а не гаснут, и при скролле назад фаза играет снова.

```js
function setPhase(key, el, on) {
  const prev = phaseState[key];
  if (on && prev !== 'in') { el.classList.remove('is-out'); el.classList.add('is-in'); phaseState[key] = 'in'; }
  else if (!on && prev === 'in') { el.classList.add('is-out'); el.classList.remove('is-in'); phaseState[key] = 'out'; }
}
```

**Тема хедера.** Каждый кадр движок берёт линию `y + 37px` (центр хедера), находит секцию под ней и копирует её `data-header` в `header[data-theme]` и `.brand[data-theme]`. Атрибут пишется только при смене. Переход цвета — CSS transition 0,5 с. Пока логотип не доехал до хедера (`y < 0.66vh`), тема принудительно тёмная.

| Тема | Кнопки | Логотип |
| --- | --- | --- |
| dark (над фото, красным, футером) | rgba(255,255,255,.16) + `backdrop-filter: blur(14px)`, белый текст | белый |
| light (над `--paper`) | сплошной `--paper`, текст `--ink` | `--ink` |

Логотип перекрашивается через маску: PNG лежит в `mask: url(logo.png)`, а цвет даёт `background: currentColor`. Один файл — любой цвет, в том числе красный в футере.

## Секции: вёрстка и анимация

Каждая секция ниже описана одинаково: разметка, что видит зритель, точные параметры, код из `index.html`.

### 0. Лоадер

**Разметка.** `.loader` — fixed на весь экран, `z-index: 100`, фон `--paper`. Внутри: заголовок из двух `.line`, между ними `.loader__slot` с портретом; внизу линия прогресса 1 px и счётчик процентов справа.

**Что видит зритель.**

1. Строки поднимаются из масок, заголовок проявляется с opacity 0,14 до 1 за 1 с.
2. Линия растёт слева направо, счётчик идёт 0→100 %. Значение — минимум из доли загруженных картинок и времени/1,6 с, сглаженное lerp 0,12. Итог: не быстрее 1,6 с и не обгоняет реальную загрузку.
3. На 30 % слот раскрывается по ширине 0 → 1,7em за 1,1 с (`ease-in-out-quart`) и раздвигает строки.
4. На 100 % — пауза 650 мс, затем FLIP: фото из слота клонируется в fixed-слой `.loader__zoom` и за 1,2 с вырастает до всего экрана. Заголовок одновременно гаснет.
5. Под клоном уже лежит hero с тем же фото и тем же `object-position: 50% 20%` — клон гаснет за 0,5 с, стык невидим. Хедер выезжает сверху (`translateY(-120%) → 0`, 1 с), Lenis разблокируется.

На оригинале то же делается кейфреймами `mask-expand` / `content-expand`; FLIP выбран, чтобы точка старта всегда совпадала со слотом при любом кегле.

```js
const r = slot.getBoundingClientRect();
const z = document.createElement('div'); z.className = 'loader__zoom';
Object.assign(z.style, { left: r.left+'px', top: r.top+'px', width: r.width+'px', height: r.height+'px' });
document.body.appendChild(z);
// два кадра — чтобы стартовая геометрия успела отрисоваться
requestAnimationFrame(() => requestAnimationFrame(() =>
  Object.assign(z.style, { left: 0, top: 0, width: vw+'px', height: vh+'px' })));
// CSS: .loader__zoom { transition: all 1.2s var(--ease-in-out-quart) }
```

### 1. Хедер и логотип

**Разметка.** `.header` — fixed, высота 75 px, отступ сверху 30 px, две кнопки по краям (`space-between`). Логотип — отдельный fixed-элемент `.brand` вне хедера: один и тот же узел служит большим лого в hero и маленьким в хедере. Ширина — min(46vw, 640px), `aspect-ratio: 1400/323`.

**Анимация (scrubbed).** Прогресс `lp = easeInOutCubic(map(y, 0, 0.66vh))`. Масштаб идёт от 1 до `112px / ширина` (84 px на мобиле), `translateY` — от центра экрана до центра хедера (38 px). `transform-origin: 50% 0`. На оригинале замерено: scale 1 → 0,892 → 0,784 → 0,676 → 0,578 на скролле 0 / 150 / 300 / 450 / 600 px, дальше замирает.

```js
const lp = easeInOutCubic(map(y, 0, vh * .66));
const s  = lerp(1, targetW / brand.offsetWidth, lp);
brand.style.transform = `translate3d(-50%, ${lerp(startTop, endTop, lp)}px, 0) scale(${s})`;
```

**Кнопки.** `.btn` — 45 px, uppercase 12 px / 500 / tracking 0.12em, первое слово курсивом серифом 15 px. Hover: псевдоэлемент цвета `--peak` заливает кнопку снизу (`scaleY 0 → 1`, 0,45 с), текст становится светлым.

### 2. Hero

**Разметка.** `section.hero` 100svh → `.hero__mask` (absolute, `clip-path: inset(var(--iy) var(--ix))`) → `.hero__media` с портретом (`object-fit: cover`, `object-position: 50% 20%`) + `.hero__shade` (радиальное затемнение под логотипом и градиент снизу) + теглайн + индикатор скролла.

**Анимация (scrubbed, за первые 0,5 экрана):**

| Свойство | Старт | Конец | Кривая |
| --- | --- | --- | --- |
| `--ix` (бока маски) | 0 % | 6 % | easeOutQuart |
| `--iy` (верх/низ маски) | 0 % | 7,5 % | easeOutQuart |
| scale фото | 1,06 | 1,00 | easeOutQuart |
| translateY фото | 0 | 0,25 × y (отстаёт от скролла) | линейно |
| opacity теглайна | 1 | 0 к 0,22 экрана | линейно |

Итоговые 6 % / 7,5 % — те же цифры, что измерены на оригинале к 450 px скролла: полноэкранный кадр сжимается в «карточку» с полями и уезжает вверх. Маска сделана через CSS-переменные, чтобы JS писал два числа, а не строку `inset(...)`.

```css
.hero__mask { position:absolute; inset:0; overflow:hidden; clip-path: inset(var(--iy,0%) var(--ix,0%)); }
```

```js
const hp = easeOutQuart(map(y, 0, vh * .5));
heroMask.style.setProperty('--ix', hp * 6 + '%');
heroMask.style.setProperty('--iy', hp * 7.5 + '%');
heroMedia.style.transform = `translate3d(0, ${y * .25}px, 0) scale(${1.06 - .06 * hp})`;
```

Индикатор скролла — белая чёрточка 1×46 px, внутри неё бесконечно пробегает заливка (`@keyframes cue`, 2,2 с).

### 3. Discover — «Practice over hype»

**Разметка.** `section.discover` высотой 320vh. Внутри одна `.discover__stage` — `position: sticky; top: 0; height: 100svh`. В сцене четыре слоя: `<canvas>` на весь экран, заголовок 1 (top 22vh), заголовок 2 (bottom 9vh), блок контента по центру (ширина ≤ 560 px). Секция длиннее экрана на 2,2vh — это и есть «дорожка», по которой играет анимация.

На оригинале здесь fixed WebGL-сцена с 3D-моделью. Для PEAK она заменена собственной «звуковой сферой» на Canvas 2D: 2600 точек (1400 на мобиле) на сфере Фибоначчи, радиус модулирован синусами как сигнал. Без Three.js, перспектива считается вручную.

**Хореография по прогрессу `dp`** (0 = верх секции за 0,3 экрана до стыковки, 1 = конец sticky):

| dp | Сфера (scrubbed) | Текст (triggered) |
| --- | --- | --- |
| 0 → 0,35 | поднимается из-за нижнего края (cy 105 % → 52 % высоты), easeOutQuart | с 0,08: «Practice / over hype,» выезжает из масок |
| 0,35 → 0,45 | висит по центру, вращается | — |
| 0,42 | — | заголовок 1 уезжает вверх, «Craft over / noise.» выезжает внизу |
| 0,45 → 0,78 | сплющивается в кольцо-волну: y × (1 − 0,9·flat), наклон rotX 0,35 → 1,25 рад, амплитуда 0,06 → 0,16, ширина ×1,35 | — |
| 0,72 → 0,9 | гаснет до 22 % и остаётся фоном | с 0,74: заголовок 2 уезжает, блок At a Glance выходит fade-up со стаггером 80 мс |
| 1 | sticky отпускает, сцена уезжает вверх вместе с контентом | — |

Вращение сферы — сумма времени и скролла (`rotY = time·0.00012 + dp·5.2`): в покое она живёт, при скролле крутится под рукой. Рисуется только когда секция в вьюпорте. Прозрачность точки зависит от глубины (0,18–0,8), размер — 1,3 px × перспектива.

```js
// одна точка: сигнал → сплющивание → поворот Y → поворот X → перспектива
const wob = 1 + amp * Math.sin(y * 9 + time * .0016) * Math.cos(x * 7 - time * .001);
x *= wob; y *= wob * (1 - .9 * flat); z *= wob;
const x1 = x * cosY - z * sinY, z1 = x * sinY + z * cosY;
const y2 = y * cosX - z1 * sinX, z2 = y * sinX + z1 * cosX;
const persp = 2.6 / (2.6 + z2);
ctx.globalAlpha = (.18 + .62 * (1 - (z2 + 1) / 2)) * fade;
ctx.fillRect(cx + x1 * R * persp * (1 + .35 * flat), cy + y2 * R * persp, 1.3 * persp, 1.3 * persp);
```

**Блок At a Glance.** Аптайтл, подзаголовок гротеском 500, сетка KPI 3×2 (на мобиле 2×3) с волосяными линиями через `gap: 1px` на тёмном фоне, тёмная кнопка «Read the timeline».

### 4. Таймлайн-степпер

Самая сложная сцена: маленький кадр вырастает в полноэкранный, потом поверх него справа наезжают ещё пять панелей, а по низу едет подпись-маршрут.

**Разметка.** `section.stepper` → `.stepper__stage` (sticky, 100svh) → четыре слоя:

- `.stepper__head` — аптайтл и заголовок «from Belgorod / to the main stage», top = header + 9vh;
- `.stepper__grow` — контейнер, чьи left/top/width/height пишет JS; внутри 6 панелей `article.panel` (absolute inset 0, `isolation: isolate`);
- `.stepper__dots` — 6 точек 5 px слева по центру;
- `.stepper__cap` — одна строка `white-space: nowrap` размером `--t-d1` внизу.

Каждая панель: `.panel__img` (фото с запасом под параллакс), градиент снизу через `::after`, `.panel__copy` — годы, заголовок, абзац из исходника. Четвёртая панель (Since 2022) без фото: красный фон и два гигантских числа, 2,000–2,500 и 8,000.

**Дистанции.** Высота секции считается в `measure()`:

```js
const GROW = () => vh * 1.1;   // рост кадра
const WIPE = () => vh * 0.9;   // на каждую шторку
step.style.height = vh + GROW() + WIPE() * (panels.length - 1) + vh * .5 + 'px';   // ≈ 7,1 экрана
```

**Фаза A — рост (0 → 1,1 экрана, easeInOutCubic).** Кадр стартует с min(32vw, 460) × 0,82 и верхом на 62 % высоты — под заголовком. Растёт до 100vw × 100vh, наезжая на заголовок. Заголовок гаснет на отрезке g 0,55–0,9, текст первой панели проявляется на 0,75–1. На оригинале замерено: 450×450 → 623×550 → 823×650 → 1050×750 → 1303×850 → 1440×900 с шагом 200 px скролла, то есть рост за \~1000 px.

**Фаза B — шторки (по 0,9 экрана на панель).** Панели 1–5 лежат стопкой и открываются справа налево через `clip-path`. Фото внутри каждой едет навстречу шторке: translateX +100 → −100 px при scale 1,14. Те же числа (scale 1,13889, сдвиг ±100 px) измерены на оригинале.

```js
panels.forEach((pn, i) => {
  if (i === 0) return;
  const pp = map(sy, GROW() + WIPE() * (i - 1), GROW() + WIPE() * i);
  pn.style.clipPath = `inset(0 0 0 ${(1 - easeInOutCubic(pp)) * 100}%)`;
  pn.firstElementChild.style.transform = `translate3d(${lerp(100, -100, pp)}px,0,0) scale(1.14)`;
  if (pp > .5) active = i;   // активная точка слева
});
```

**Подпись-маршрут.** «from Belgorod, to Moscow, to the World.» едет справа налево через всю фазу B (от +55vw до полной ширины строки). Активный город — opacity 1, остальные 0,42; треть пути = один город. На оригинале такая же строка-цепочка из трёх звеньев с подсветкой текущего.

**Фаза C — выход.** Последние 0,5 экрана — запас: последняя панель стоит целиком, потом sticky отпускает и сцена уезжает вверх.

Важно: `.panel { isolation: isolate }`. Без этого текст первой панели (`z-index: 2`, без clip-path) пробивает все следующие панели.

### 5. Большие заголовки (Today, Residencies)

**Разметка.** `section.ltitle.reveal`, текст по центру, поля clamp(80px, 12vh, 140px) сверху и clamp(50px, 7vh, 80px) снизу. Аптайтл (курсив + прописные) и две `.line` со строками заголовка.

**Маскированная строка** — базовый приём всего сайта. Внешний `span.line` — маска с `overflow: hidden`, внутренний `span` едет с `translateY(105%)` в 0. `padding-bottom: .08em` с отрицательным margin спасает хвосты g/y/p от обрезки.

```css
.line { display:block; overflow:hidden; padding-bottom:.08em; margin-bottom:-.08em }
.line > span { display:inline-block; transform:translateY(105%); transition:transform 1.1s var(--ease-out-quart) }
.is-in .line > span { transform:none }
.is-in .line:nth-child(2) > span { transition-delay:.08s }   /* стаггер 80 мс */
.is-out .line > span { transform:translateY(-105%); transition:.7s var(--ease-in-out-cubic) }
```

### 6. Диптих

**Разметка.** Грид 1fr 1fr с gap 10 px. Левая колонка растягивается на всю высоту правой, внутри — `.diptych__sticky` (`sticky; top: gutter; height: 100vh − 2·gutter`) с портретом. Правая колонка — флекс-столбец: ряд из двух фото 4:5, текст «PEAK on stage» с кнопкой, широкое фото 16:11, текст «Education & culture». Пока справа едет контент, портрет слева стоит.

**Появление фото (triggered).** `.media` стартует с `clip-path: inset(100% 0 0 0)` и фото scale 1,18. По `.is-in` шторка открывается снизу вверх за 1,3 с (`ease-in-out-quart`), фото отъезжает до 1,04 за 1,8 с (`ease-out-expo`).

**Параллакс (scrubbed).** Внутри маски обёртка `.px` с запасом ±6 % по высоте едет от −5 % до +5 %, пока блок проходит экран снизу доверху. Больше ±10 % читается как шаблонный параллакс. Текст не параллаксится никогда.

```js
const t = map(y, m.top - vh, m.top + m.h);
px.style.transform = `translate3d(0, ${lerp(-5, 5, t)}%, 0)`;
```

### 7. Сетка резиденций + sticky-кнопка

**Разметка.** `.rgrid` — 5 колонок (2 на мобиле), большие воздушные зазоры: clamp(24px, 5vw, 90px) по вертикали, clamp(16px, 3.6vw, 60px) по горизонтали. Плитки 4:5 генерируются из массива `VENUES` (12 площадок из исходника). В позиции 2, 8 и 13 вставлены фото-плитки, чтобы сетка не была списком. Плитка: номер «04 / 12», название серифом, город курсивом, внизу хэндл и бейдж Resident. Плитки с Instagram — ссылки.

**Появление (triggered).** opacity 0 → 1 и translateY 60 px → 0 за 1–1,2 с; задержка = номер колонки × 70 мс, ряд выезжает волной слева направо. Hover: красная заливка снизу за 0,6 с, текст светлеет.

**Sticky-кнопка («push»).** Поверх сетки лежит абсолютный `.push-rail` на всю её высоту с отступами 22vh сверху и снизу. Кнопка «Follow @peak.dj» внутри — `position: sticky; top: calc(50vh − 22px)`: пока сетка проезжает, она висит по центру экрана, в конце уезжает вместе с сеткой. Рельс с `pointer-events: none`, кнопка — `auto`, плитки под ней кликаются. Чистый CSS, без JS.

### 8. Цитата с расходящимися строками

**Разметка.** Красная секция `--peak`, `blockquote` кеглем clamp(46px, 9.4vw, 170px), прописные. Пять `.qline`, каждая — flex по центру из двух `span`-половин, `white-space: nowrap`. Текст собран из исходника: «turning floors into communities, not just crowds» и «practice over hype, craft over noise».

**Анимация (scrubbed).** Для каждой строки свой прогресс t: 0 — центр строки на нижнем краю экрана, 1 — на верхнем. Разъезд k = sin²(πt): строка входит собранной, в середине пути половины расходятся максимально, наверху снова сходятся. Амплитуда min(20vw, 300px); левая половина уходит влево на A·k, правая вправо на 0,85·A·k; чётные строки на 20 % слабее. Строки проходят пик по очереди — идёт волна. На оригинале механика та же: пики до ±380 px и возврат к 0.

```js
const amp = Math.min(vw * .2, 300);
qlines.forEach((l, i) => {
  const m = L.q[i];
  const t = map(y + vh, m.top + m.h * .5, m.top + m.h * .5 + vh);
  const k = Math.sin(t * Math.PI) ** 2 * (i % 2 ? 1 : .8);
  l.children[0].style.transform = `translate3d(${-amp * k}px,0,0)`;
  l.children[1].style.transform = `translate3d(${amp * k * .85}px,0,0)`;
});
```

Пункты выезжают из масок с задержками 0,35 / 0,42 / 0,49 / 0,56 / 0,63 с, то есть когда шторка уже накрыла половину экрана. Lenis останавливается, Esc закрывает. ## Адаптив, reduced motion, известные ловушки

Сайт проверен в headless Chromium на 1440×900 и 390×844: 42 скриншота по всей длине, ошибок JS нет. Все сцены работают и на мобиле, меняется только раскладка.

**Брейкпоинты**

| Ширина | Что меняется |
| --- | --- |
| ≤ 900 px | KPI 2 колонки; диптих в одну колонку, портрет без sticky (75vh); сетка резиденций 2 колонки; профили списком; точки степпера скрыты; футер 2 колонки |
| ≤ 700 px (JS) | сфера 1400 точек и радиус 0,34 от меньшей стороны; логотип в хедере 84 px |
| ≤ 560 px | заголовок лоадера до 46 px; цифры на красной панели до 72 px и обе сверху; в плитках скрыт хэндл; заголовки секций 11,5vw |

Высоты экранных сцен — `100svh`, чтобы панель Safari не дёргала sticky. Тач-скролл не сглаживается (`syncTouch: false`), нативная инерция сохранена.

**Reduced motion.** При `prefers-reduced-motion: reduce` лоадер удаляется сразу, Lenis не создаётся, все transition и animation сжаты до 0,01 мс. Скраб-эффекты остаются привязаны к руке пользователя, но без инерции.

**Что сломается и как чинить**

| Симптом | Причина | Решение |
| --- | --- | --- |
| Текст первой панели просвечивает сквозь следующие | `z-index` текста выходит из панели без своего стекинг-контекста | `.panel { isolation: isolate }` |
| Ревилы и фазы срабатывают не в тех местах | шрифт загрузился после `measure()` | повторный `measure()` по `document.fonts.ready` и `load` |
| Мёртвое место или скачок после ресайза | высота степпера посчитана под старый vh | `measure()` + `lenis.resize()` на `resize` |
| Логотип не виден локально | CSS-маска не грузится с `file://` (CORS) | открывать через локальный сервер: `python3 -m http.server` |
| Хвосты g/y/p обрезаны в заголовках | маска без нижнего запаса | `padding-bottom: .08em` + `margin-bottom: -.08em` на `.line` |
| Скролл двоится или тормозит | `scroll-behavior: smooth` в CSS поверх Lenis | не добавлять это свойство; якоря только через `lenis.scrollTo` |
| Джанк на скрабе | анимация layout-свойств | только `transform`, `clip-path`, `opacity`; исключение — размеры `.stepper__grow`, они в sticky-сцене с `will-change` |
| Строки цитаты уходят за край и дают горизонтальный скролл | амплитуда больше полей | `overflow: hidden` на `.quote` и `overflow-x: hidden` на `body` |

**Как менять контент**

- Резиденции — массив `VENUES` в начале скрипта: `[название, город, хэндл, ссылка]`. Фото-плитки — объект `IMG_TILES` (позиция → файл).
- Главы таймлайна — `article.panel` в HTML; длина степпера пересчитывается сама по числу панелей. Точек `.stepper__dots i` должно быть столько же.
- Темп степпера — константы `GROW` (1,1vh) и `WIPE` (0,9vh).
- Фразы цитаты — `.qline` с двумя `span`; разрез делать по границе слов.

**Чек-лист приёмки**

- [ ] Один rAF-цикл на страницу, второго нет в Performance
- [ ] Лоадер не короче 1,6 с, стык с hero невидим
- [ ] Логотип садится в центр хедера и перекрашивается на светлых секциях
- [ ] Ни один текст не привязан к скроллбару по opacity
- [ ] Ресайз в любой точке скролла не оставляет пустоты в степпере
- [ ] На 390 px нет горизонтального скролла, названия площадок не вылезают из плиток
- [ ] Меню открывается, Esc закрывает, якоря доезжают плавно
- [ ] Все ссылки на Instagram, YouTube, SoundCloud, Apple Music, Deezer и резиденции открываются в новой вкладке
