# PEAK — сайт DJ Andrey Glotov

Ты работаешь над одностраничным сайтом PEAK. Сайт уже собран и работает. Задача — дорабатывать его по моим запросам, не ломая систему движения и токены.

## Файлы

```
peak-site/
├── index.html        вся вёрстка, CSS (14 пронумерованных блоков) и JS-движок в одном файле
├── assets/           logo.png (белый, через CSS-маску), photos/ (фото сайта по блокам, см. SPEC «Фото по блокам»), fonts/ (woff2)
├── docs/SPEC.md      полная спека: токены, карта секций, движок, каждая анимация с параметрами, раскадровка скролла, ловушки
└── CLAUDE.md         этот файл
```

`docs/SPEC.md` — источник правды. Прочитай его целиком до первой правки. Если меняешь механику, тайминг или структуру секции, обнови соответствующий раздел SPEC.md в том же коммите.

## Референс

https://www.verostudio.com/ — по нему собрана скролл-механика (лоадер, докинг логотипа, inset-маска hero, sticky-сцены, рост кадра + горизонтальные шторки, диптих, сетка с sticky-кнопкой, цитата с расходящимися строками).

Правила работы с референсом:
- Используй его только чтобы смотреть и измерять поведение: тип эффекта, дистанции скролла, кривые, длительности, композицию.
- Не копируй его HTML, CSS, JS, тексты, фото, видео, 3D-модели и шрифты (Louize Display и Beausite Classic — платные). Всё реализуется своим кодом.
- Весь контент — только PEAK: тексты, ссылки и изображения, которые уже есть в проекте или которые я пришлю.

Как измерять референс (Chrome DevTools или Playwright, вьюпорт 1440×900):
1. Найди нужную секцию по структуре DOM (классы CSS Modules вида `Section-module__hash__part`).
2. Прокрути на 8–10 точек (`scrollTo({top, behavior:'instant'})`, пауза 500 мс) и на каждой сними `getComputedStyle(el).transform`, `clipPath`, `opacity` и `getBoundingClientRect()`.
3. Переведи замеры в прогресс 0–1 по секции и сравни с нашей реализацией.
4. Кривые и длительности — из `document.styleSheets` (токены `--ease-*` на `:root`).

## Правила кода

- Стек: чистый HTML/CSS/JS + Lenis 1.1.13 (jsDelivr). Не добавляй GSAP, React, сборщик и другие библиотеки без моего согласия.
- Цвета, шрифты, кривые — только через токены из `:root`. Новый цвет = новый токен.
- Палитра красно-чёрная: красная основа `--red`, чёрные секции `--black`, текст `--fg`. Чёрный текст на красном не ставим (контраст ниже WCAG).
- Шрифты только узкие, вытянутые по вертикали, локально из `assets/fonts/`: Heading Now 14 (`--f-display`), Moniqa Narrow Italic (`--f-accent`, весь `<em>`), Oswald (`--f-body`). Широкие начертания и trial-файлы Heading Now не используем.
- Один `requestAnimationFrame` на страницу: `raf()` → `lenis.raf()` → `tick()`. Не заводи второй цикл и не вешай scroll-листенеры.
- Два типа анимаций, не смешивать:
  - **triggered** (весь текст, появление фото, плиток, кнопок): класс `.is-in` от IntersectionObserver или `setPhase()` внутри sticky-сцен, дальше CSS transition;
  - **scrubbed** (маски, рост, шторки, параллакс, цитата, логотипы): прогресс `map(y, start, end)` в `tick()`.
- Текст никогда не привязывай к скроллу по opacity.
- В `tick()` пиши только `transform`, `clip-path`, `opacity` и CSS-переменные. Размеры секций и офсеты — в `measure()`, не в `tick()`.
- Новая секция = своя пара `data-header="dark|light"`, свой блок CSS с номером, своя ветка в `tick()` (если scrubbed), запись в `measure()`.
- Сохраняй `prefers-reduced-motion`, `100svh` для экранных сцен, `isolation: isolate` на панелях степпера.
- Адаптив: 1440, 900, 700 (JS), 560 и 390 px должны работать без горизонтального скролла.

## Как проверять

1. Запускай через сервер, не через `file://` — CSS-маска логотипа на `file://` не грузится:
   `cd peak-site && python3 -m http.server 8765`
2. После каждой правки сними скриншоты Playwright на 1440×900 и 390×844: лоадер (0,3 / 1,2 / 3,2 с) и скролл по точкам из раздела «Раскадровка скролла» в SPEC.md. Проверь консоль на ошибки.
3. Посмотри на скриншоты сам, прежде чем сказать, что готово.

## Формат ответа

Коротко, по-русски: что поменял, в каких блоках `index.html`, что проверил. Если у задачи несколько решений — дай 2–3 варианта и подожди выбора, прежде чем делать большую переделку.
