# PLAKSA — сайт DJ PLAKSA

Ты работаешь над сайтом PLAKSA: open format DJ, Shanghai · Moscow. Сайт уже собран и работает. Задача — дорабатывать его по моим запросам, не ломая механику, токены и структуру.

## Файлы

```
plaksa-site/
├── index.html        вся вёрстка, CSS (9 пронумерованных блоков) и JS в одном файле
├── assets/           7 фото из пресс-кита + 6 кропов (.jpg)
├── docs/SPEC.md      спека: токены, карта страниц, стена, меню, лайтбокс, страницы, ловушки
└── CLAUDE.md         этот файл
```

`docs/SPEC.md` — источник правды. Прочитай его целиком до первой правки. Если меняешь механику, тайминг или структуру, обнови соответствующий раздел SPEC.md в той же правке.

## Референс

https://www.juliajohnson.com/ — по нему собрана механика: лоадер-шторка с вордмарком, бесконечная стена фото с дрейфом / драгом / колесом, меню с цветом и фото по наведению, листинг в 6 колонок, текстовые страницы одним крупным кеглем, fade-переходы между страницами.

Правила работы с референсом:
- только смотреть и измерять поведение: тип эффекта, дистанции, кривые, длительности, сетку;
- не копировать его HTML, CSS, JS, тексты, фото, вордмарк и шрифты — всё делается своим кодом;
- контент только PLAKSA: тексты и фото из пресс-кита или то, что я пришлю.

Как измерять (Chrome DevTools или Playwright, 1440×900): найди элемент в DOM, сними `getComputedStyle().transform / opacity / transition` и `getBoundingClientRect()` в нескольких моментах времени или положениях; правила CSS — через `document.styleSheets`. Для стены — позиции плиток с интервалом 500 мс (скорость дрейфа) и после `WheelEvent`.

## Правила кода

- Стек: HTML/CSS/JS + Lenis 1.1.13. Без GSAP, React, сборщика и новых библиотек без моего согласия.
- Цвета, шрифт, кривые — только через токены `:root`. Схема страницы — через `body[data-page]` (`--page-bg`, `--page-fg`, `--btn-bg`, `--btn-bar`).
- Одна гарнитура (Inter Tight) и один крупный кегль `--t-big`. Новые размеры и веса не добавлять.
- Один `requestAnimationFrame` на сайт. Стена считается только на home и только когда закрыты меню и лайтбокс.
- Все входы стены пишут в цель камеры (`cam.tx/ty`), позиция догоняет lerp 0,1. Не двигай плитки напрямую.
- Фото добавляются только через массив `PHOTOS` — тогда они попадут на стену, в листинг и лайтбокс.
- Сохраняй: порог клика 6 px, деление дельты драга на 1,15, `prefers-reduced-motion`, 100svh, `<meta charset="utf-8">`.
- Адаптив: 1440, 900, 390 px без горизонтального скролла.

## Как проверять

1. Только через сервер: `cd plaksa-site && python3 -m http.server 8766`.
2. После правки — скриншоты Playwright на 1440×900 и 390×844: лоадер (0,3 / 1,8 с), стена после 2 с дрейфа, после колеса и драга, hover и лайтбокс, открытое меню и hover пункта, каждая страница (`location.hash`) на 0 / 35 / 70 / 100 % скролла. Консоль без ошибок.
3. Сам посмотри на скриншоты, прежде чем сказать, что готово.

## Формат ответа

Коротко, по-русски: что поменял, в каких блоках `index.html`, что проверил. Если решений несколько — дай 2–3 варианта и жди выбора перед большой переделкой.
